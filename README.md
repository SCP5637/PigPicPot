# PigPicPot 托盘九宫格

## 简介

PigPicPot 是一个托盘驻留的小工具。按下 LCTRL+LALT+B 会弹出一个置顶九宫格窗口，展示 9 张来自 GitHub 仓库的随机猪图缩略图。

## 主要特性

*   启动即进入托盘，双击托盘或按热键呼出窗口。
*   窗口始终置顶，显示 3×3 的 9 张图片缩略图。
*   鼠标悬停动态 GIF 时自动播放。
*   点击任意图片即复制到剪贴板并销毁窗口。
*   点击窗口外部立即销毁窗口。
*   每次窗口销毁后异步刷新下一批缓存图片。

## 缓存逻辑

*   启动时拉取 9 张图片并缓存。
*   弹窗显示时只读取缓存。
*   窗口销毁后后台刷新缓存，供下次热键显示。

## 使用

*   运行后会在托盘出现图标。
*   LCTRL+LALT+B 呼出九宫格窗口。
*   选择图片即复制并关闭窗口。
